# Hospital Equipment Analytics Dashboard

## Project Overview

This project focuses on analyzing hospital equipment performance, utilization, and downtime to improve operational efficiency. The dashboard provides insights into equipment usage across different departments and helps identify maintenance requirements and underutilized assets.

## Objective

The objective of this project is to:

- Monitor equipment utilization rates
- Track equipment downtime
- Analyze downtime reasons
- Compare department-wise equipment performance
- Support data-driven maintenance decisions

## Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Power Query
- Data Cleaning
- Data Visualization
- Tableau (Dashboard Development)

## Key Performance Indicators (KPIs)

- Total Equipment Count
- Total Usage Hours
- Total Downtime Hours
- Average Utilization Rate
- Department-wise Equipment Performance
- Equipment Availability Analysis

## Dashboard Features

### 1. Equipment Utilization Analysis
Tracks the utilization percentage of medical equipment and identifies highly utilized and underutilized assets.

### 2. Downtime Monitoring
Monitors downtime hours across departments and equipment categories.

### 3. Downtime Reason Analysis
Provides insights into major causes of equipment downtime such as:

- Calibration
- Malfunction
- Scheduled Maintenance
- Part Replacement
- Operator Unavailability
- Software Issues

### 4. Department Performance Analysis
Compares equipment performance across hospital departments including:

- ICU
- Cardiology
- Radiology
- Nephrology
- Emergency
- OT
- General Ward

### 5. Operational Insights
Supports hospital management in improving equipment efficiency and maintenance planning.

## Business Impact

- Improved visibility into equipment performance
- Reduced operational downtime
- Better maintenance scheduling
- Enhanced resource allocation
- Data-driven decision making
